# 文件名清理

递归清理文件与文件夹名称中的特殊字符，提供目录选择和处理日志界面。

## 运行

需要 Python 3 和 Tkinter，不使用额外的第三方 Python 包。在仓库根目录执行：

```bash
python tools/filename-cleaner/main.py
```

## 使用

1. 选择目标文件夹。
2. 点击“开始清理”。
3. 在确认框中确认处理，完成后查看日志与统计。

操作范围包括选中目录内的文件和子文件夹，名称会被直接修改。保留中英文、数字、点、连字符、空格和下划线；文件扩展名保持原样。清理后名称为空时使用“未命名文件”或“未命名文件夹”，遇到重名会追加数字编号。
