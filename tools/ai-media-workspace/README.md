# AI 图像与视频生成

一个独立 HTML 页面，集中调用火山方舟的 Seedance 视频和 Seedream 图片生成接口。

## 打开

下载仓库并解压，用浏览器打开本目录的 [index.html](index.html)。不需要 Node.js、打包构建或本地服务。

GitHub 的文件预览页只显示源码，需要将文件下载到电脑后打开。

## 使用

1. 在顶部输入自己的火山方舟 API Key。
2. 切换“视频生成”或“图片生成”，选择模型。
3. 输入提示词，按需上传参考素材、调整画幅或时长。
4. 点击生成，等待任务完成并查看作品。

页面内置 Seedance 1.5 Pro、2.0、2.0 Fast，以及 Seedream 4.0、4.5、5.0 的模型入口；实际可用性以自己的方舟账号和接口响应为准。请求直接发送到方舟接口，生成消耗自己账号的服务额度。

API Key 保存在当前浏览器的本地存储中，作品记录通过 IndexedDB 保存；页面还会请求外部字体和头像资源。联网访问是生成和查询任务所必需的。
